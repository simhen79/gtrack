# Accordion

Optional or secondary detail that stays folded: advanced Round stats, distance bands, Game rules on the web.

- Each item is a `surface-secondary` tile with 18px corners; 56px header with a `card-title`-weight label, a muted summary and a chevron.
- Layout C keeps carried-over Round details folded under one line with a Change button; that line is a Surface, not an Accordion.
- Phone: `heroui-native` Accordion, same tiles.
