# Table

Lists of records: Rounds, past Practice Sessions, Users, Catalogue, LLM usage.

- Rows are `surface-secondary` tiles with 14px corners and a 6px gap, not ruled lines. Header row in `small` caps-free text.
- Numbers right-aligned in tabular figures; SG cells use `stat-sm` and `sgTone`; score in an outlined 28px pill.
- The whole row is a link to its detail page.
- Below 640px wide the table scrolls inside its card (`overflow-x: auto`); on phone use `heroui-native` ListGroup items instead.
