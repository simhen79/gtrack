# Pagination

Breadcrumbs above page titles, Pagination under long lists, Link for inline text links.

- Breadcrumbs: `small` in `muted`, the current page in foreground, `/` separators.
- Pagination: 32px controls with 10px corners; current page on `segment`.
- Link: `link` colour (foreground) with underline on hover; never orange.
- Phone: no pagination, lists scroll; use `LinkButton` for text links.
