# Chip

Short labels: SG Category badges, Level changes, status, the "why picked" note; with Badge, Avatar and Kbd.

- All chips have 6px corners and 12px/700 text.
- **SG Category badge**: `bg-cat-ott|app|shg|put` with `cat-foreground` and the three-letter code, 24px tall, `caption` text. Never show the colour without the code.
- Level up: `highlight`. Held: `surface-tertiary`. Level down: outline in `sg-negative`.
- Status: dot plus words (`success`, `warning`, `danger` dot).
- Badge: an `accent` dot on the avatar for something new.
- Avatar: initials on `highlight`, full circle, 44px in the header.
- Kbd: `surface-tertiary`, 6px corners, desktop only.
