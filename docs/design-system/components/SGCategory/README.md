# SGCategory

The four SG Categories, always in the same order with the same colour, code and icon.

| Code | Name | Token | Icon |
| --- | --- | --- | --- |
| OTT | Off the Tee | `cat-ott` | ball on tee |
| APP | Approach | `cat-app` | flag |
| SHG | Short Game | `cat-shg` | chip arc |
| PUT | Putting | `cat-put` | ball by the cup |

- Badge (Chip): code on the colour, 6px corners. Use it in rows, tables and card headers.
- Icon disc: 44px circle in the colour with a dark icon, for bigger headers and the live screen.
- Never "Around the Green", "area" or "skill area".
- Order is fixed (OTT, APP, SHG, PUT) except where a list is ranked; then it says "weakest first".
