# Progress

Progress and quantities: the SG Category split bar, upload progress, Weekly Plan completion, LLM usage.

- **Session split**: four rounded bands in the cat-* colours with 6px gaps, ordered weakest first; minutes and percentages listed under it with codes.
- ProgressBar: 8px, track `surface-tertiary`, fill `accent`.
- ProgressCircle: 12px stroke, `highlight` on `surface-tertiary`, the count in the middle.
- Meter for Levels: see LevelMeter.
