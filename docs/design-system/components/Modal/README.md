# Modal

Focused tasks and confirmations: change carried-over Round details, swap a Session Item (Modal); delete, Abandon, publish a new version (AlertDialog).

- `overlay`, 24px corners, `overlay-shadow`, `backdrop` at 60%.
- Title `title` style, body `body` in muted, actions bottom-right: the safe choice as ghost, the confirm as `danger` or `primary`. The confirm button repeats the verb.
- Phone: `heroui-native` Dialog with the same layout, buttons full width and stacked.
