# Checkbox

Facilities and features (Checkbox, CheckboxGroup), single choices (RadioGroup), settings (Switch), removable sets (TagGroup).

- Facility choices are chip-style labels with a checkbox inside, 44px tall: checked = `highlight` fill. Plain checkboxes inside forms use the same `highlight` fill.
- RadioGroup: selected ring `highlight`.
- Switch: on track `highlight`, thumb `highlight-foreground`; off track `surface-tertiary`.
- Phone: wrap each in `ControlField` so the whole 44px row is tappable.
