# TextField

Text entry with its label, description and error.

- Field: 52px (44px for search), `field-background`, 1px `field-border`, 12px corners, 16px/600 text. Focus: 2px `focus` ring, offset 2px.
- Label above in `label` style; description under in `small`; error replaces the description in `danger` and turns the border `danger`.
- Placeholders show an example, never the label.
- Phone: `heroui-native` TextField with Label, Input, Description and FieldError children.
