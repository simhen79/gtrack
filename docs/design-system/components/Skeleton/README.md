# Skeleton

Loading states: Skeleton blocks shaped like the content, Spinner for a running Generation or save.

- Skeleton blocks take the content's own corners: 6px for text lines, 14–18px for rows, 24px cards stay as cards.
- Fill `surface-tertiary` (lines) and `surface-secondary` (rows), HeroUI shimmer.
- Spinner: `accent` arc on `surface-tertiary`, 20px inline, 32px centred with a sentence saying what is happening.
- Phone: SkeletonGroup to animate a card's skeletons together.
