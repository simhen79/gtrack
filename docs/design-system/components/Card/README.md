# Card

The bento card every screen is made of, plus Surface for tiles inside it.

- Card: `surface`, 24px corners, no border, no shadow; padding 24 (web) or 18–20 (phone); 16px gap between cards.
- Header: `card-title` on the left, a 32px ghost ··· menu on the right.
- One headline number per card in a Numbers style; supporting text `small`.
- Inside a card, rows and tiles are Surface `surface-secondary` with 18px corners and 6–10px gaps. Use Separator only when tiles would be too heavy.
