# ToggleButtonGroup

Segmented choice of 2–4 mutually exclusive options: scoring type, chart range, calendar view.

- Track `surface-secondary`, 14px corners, 4px inset. Selected segment `segment` (white) with `segment-foreground`, 10px corners.
- Use Tabs instead when the choice changes the page; use Select when there are more than four options.
- Phone has no ToggleButtonGroup: use `heroui-native` Tabs with the same styling.
