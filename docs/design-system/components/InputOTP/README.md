# InputOTP

The 6-digit sign-in code on web and phone.

- Six slots, 52×60, 12px corners, 8px gap, `stat`-weight digits. Active slot: 2px `focus` border.
- Auto-submit on the sixth digit; paste fills all slots.
- The same "Check your email" screen shows for uninvited emails, so copy never confirms whether an account exists.
