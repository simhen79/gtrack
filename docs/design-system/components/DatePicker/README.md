# DatePicker

Round date (DatePicker + Calendar), Trends and past-session filters (DateRangePicker), planned visit time (TimeField).

- Calendar on `overlay`, 24px corners; day cells 40px with 10px corners. Selected = `segment`; today = 2px `highlight` ring; other-month days `muted`.
- Range fill `accent-soft`.
- Defaults to the last Round's date + today, since Rounds are entered after play.
- Phone: Round entry is web-only; the phone uses the native date picker only for the Weekly Plan.
