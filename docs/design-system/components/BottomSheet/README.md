# BottomSheet

Phone sheets: Game rules in a live session, swap a Session Item, pick Facilities. The web equivalent is Sheet (bottom/side panels). The avatar sheet on the phone holds the theme choice, Practice Grounds, Admin and Sign out.

- `surface` (`overlay` outside Range), 24px top corners, a 44×5 grab handle, 20px padding.
- In a live session (Range theme, shown here) text is large: 26px title, 18px body; the close action is a 64px `accent` button.
