# BottomSheet

Phone sheets: Game rules in a live session, swap a Session Item, pick Facilities. Web equivalents are Sheet (bottom/side panels) and Drawer (the narrow-web nav).

- `surface` (`overlay` outside Range), 24px top corners, a 44×5 grab handle, 20px padding.
- In a live session (Range theme, shown here) text is large: 26px title, 18px body; the close action is a 64px `accent` button.
- Web Drawer slides from the left with the nav pills stacked full-width.
